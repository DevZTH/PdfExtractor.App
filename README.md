# Изображения из PDF

Простое настольное приложение на C# / .NET 10 и Avalonia. Извлекает встроенные
растровые изображения через **pdfimages** из Poppler. Windows и Linux x64;
обе версии и Windows-инсталлятор собираются **на Linux**.

## Использование

1. Нажмите **Выбрать PDF…** либо перетащите PDF в окно. Можно выбрать несколько файлов.
   Перетаскивание на EXE или ярлык Windows тоже поддерживается: пути принимаются
   аргументами командной строки. В Linux установленный `.desktop` использует `%F`;
   поддержка перетаскивания на значок зависит от файлового менеджера.
2. Задайте минимальную ширину и высоту в пикселях. Изображение должно удовлетворять
   **обоим** ограничениям. `0` отключает соответствующее ограничение.
3. Выберите **JPEG** (по умолчанию), PNG, WebP или BMP.
4. Задайте шаблон имени. По умолчанию `image_` → `image_0001.jpeg`.
   Поддерживаются `{pdf}`, `{page}`, `{index}` и `{index:0000}`.
   Например: `{pdf}_p{page}_{index:000}` → `report_p2_001.jpeg`.
   Если номер не указан, он добавляется автоматически. Расширение добавляет приложение.
5. Пустая папка сохранения означает `<папка PDF>/<имя PDF без расширения>/`.
   Например, `/docs/book.pdf` → `/docs/book/`. Указанная вручную папка общая
   для всех выбранных PDF. Несуществующая папка создаётся.
6. Нажмите **Извлечь изображения**. Можно отменить операцию; уже записанные файлы
   сохранятся. При совпадении имени добавляется суффикс `_1`, `_2` и т. д.

Изображения сохраняются в исходном разрешении. Отдельные маски прозрачности
не выдаются как изображения: маска присоединяется к основной картинке.
PNG и WebP поддерживают прозрачность; JPEG и BMP используют белый фон.
JPEG/WebP кодируются с качеством 95. Это не рендеринг страниц: векторная графика
и текст не превращаются в картинки. Защищённые паролем PDF без доступа
вызывают ошибку с сообщением Poppler; ввод пароля не реализован.

## Запуск из исходников

Нужен **.NET 10 SDK**. Linux: установите Poppler (`sudo apt install poppler-utils`,
`sudo pacman -S poppler` или `sudo dnf install poppler-utils`). Для GUI нужны
стандартные библиотеки рабочего стола X11 и fontconfig; в Wayland используется XWayland.

```bash
dotnet run --project src/PdfExtractor.App -- "/path/to/book.pdf"
```

При запуске исходников на Windows добавьте каталог Poppler `Library/bin` в PATH
или укажите полный путь к `pdfimages.exe` в переменной `PDFIMAGES_PATH`.
Установочная версия уже содержит Poppler и .NET runtime.

## Сборка из Linux

Нужны .NET 10 SDK, `bash`, `curl`, `unzip`, `sha256sum`, `tar`.
Для Windows-инсталлятора также нужен **NSIS** (`makensis`):
на Debian/Ubuntu `sudo apt install nsis`. Wine и Windows SDK для сборки не нужны.

```bash
bash scripts/build.sh          # Linux + Windows + Windows-инсталлятор
bash scripts/build.sh linux    # Только Linux
bash scripts/build.sh windows  # Windows + инсталлятор
```

Можно указать нестандартные пути: `DOTNET=/path/to/dotnet MAKENSIS=/path/to/makensis bash scripts/build.sh`.
Скрипт скачивает фиксированный Windows-релиз Poppler **26.09.0-0**, проверяет SHA-256
и включает `pdfimages.exe`, DLL и файлы данных в установщик. Последующие сборки
используют проверенный архив из `vendor/poppler-windows/`.

Результаты:

| Файл / папка | Назначение |
| --- | --- |
| `artifacts/PdfImageExtractor-Setup-x64.exe` | Windows-инсталлятор для текущего пользователя, без прав администратора |
| `artifacts/win-x64/` | Переносимая Windows-версия: копировать целиком |
| `artifacts/PdfImageExtractor-linux-x64.tar.gz` | Автономная Linux-версия (.NET runtime включён) |
| `artifacts/linux-x64/` | Распакованная Linux-версия |
| `artifacts/PdfImageExtractor-source.tar.gz` | Исходники приложения и скрипты сборки |

В Windows не требуются отдельно установленные .NET и Poppler. Инсталлятор создаёт
ярлыки, удаление программы и пункт «Открыть с помощью» для PDF. В Linux Poppler
устанавливается через пакетный менеджер. Архив можно распаковать и запустить
`./PdfImageExtractor`; `bash install.sh` устанавливает в каталог пользователя
и добавляет приложение в меню.

## Проверка

```bash
dotnet test tests/PdfExtractor.Tests/PdfExtractor.Tests.csproj -c Release
```

Тесты извлечения используют настоящий `pdfimages`: он должен быть доступен в PATH
или через `PDFIMAGES_PATH`. Тестовые PDF создаются самим C#-кодом, без внешних файлов.
Проверяются форматы, размеры, прозрачность, имена, повторная запись, ошибочный PDF,
отмена и загрузка GUI в headless-режиме. CI собирает обе платформы на Ubuntu.
